# Format reference for the ainotes-task default-branch cache.
#
# The live cache is NOT this file: ainotes-task reads and appends to
# <workspace-root>/.ai-notes/default-branches.txt, creating it on first use.
# One line per repo: "<repo> <branch>". Lines starting with "#" are ignored.
#
# Example:
# api-gateway main
# web-app main
# mobile-app develop
# billing-service master
